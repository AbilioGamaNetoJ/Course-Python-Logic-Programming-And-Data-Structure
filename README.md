# 🐍 Curso Completo de Lógica de Programação e Estruturas de Dados em Python

## 📚 Sobre o Curso

Este é um curso **completo e prático** de Lógica de Programação e Estruturas de Dados utilizando Python, desenvolvido com uma abordagem pedagógica progressiva que vai do básico ao avançado. O curso foi estruturado para proporcionar uma compreensão profunda dos conceitos fundamentais da programação e das estruturas de dados mais importantes.

## 🎯 Objetivos do Curso

- **Dominar** os fundamentos da lógica de programação
- **Implementar** estruturas de dados clássicas do zero
- **Compreender** análise de complexidade e otimização
- **Desenvolver** algoritmos eficientes
- **Aplicar** conceitos em projetos práticos reais
- **Construir** sistemas completos e escaláveis

- Python 3.8 ou superior
- Conhecimento básico de programação (desejável)

## 🏆 Projeto Integrador

O **Projeto Integrador** (`05_projeto_integrador.py`) é o ponto alto do curso, implementando um **sistema empresarial completo** que integra todos os conceitos aprendidos:

### 🏢 Sistema Empresarial Completo
- **Gestão de Clientes** - CRUD completo com validações
- **Catálogo de Produtos** - Controle de estoque e categorias
- **Sistema de Pedidos** - Processamento automático e status
- **Recomendações Inteligentes** - Algoritmos colaborativos e baseados em conteúdo
- **Motor de Busca** - TF-IDF e busca fuzzy
- **Análise de Dados** - Relatórios executivos e KPIs
- **Interface Completa** - CLI interativa e amigável

### 🔧 Tecnologias Integradas
- **Estruturas de Dados:** Árvores AVL, Cache LRU, Filas de Prioridade
- **Algoritmos:** Busca, Ordenação, Recomendação, Análise
- **POO:** Classes, Herança, Polimorfismo, Padrões
- **Banco de Dados:** SQLite com ORM personalizado
- **Concorrência:** Threading para processamento assíncrono
- **Análise:** Estatísticas e métricas de performance
